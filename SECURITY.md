# Security policy

## Report a vulnerability

Report security problems privately through GitHub: open the affected repository's **Security** tab and choose **Report a vulnerability**. Don't open a public issue.

Include what is affected, how to reproduce it, and the impact you see. We acknowledge reports within three working days and keep you updated until a fix is released.

## Supported versions

FireMQ is before 1.0. Security fixes go into the latest release.
